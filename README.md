# In-employee-reports: Плагин отчетов сотрудников для WordPress

## Версия 3

В версии 3 произведен полный рефакторинг кода по современным стандартам.

## Краткое описание

Плагин `in-employee-reports` предназначен для заполнения и проверки отчетов сотрудников "Иван Никитин и партнеры" по выполненным задачам непосредственно в административной панели WordPress.

## Возможности

- **Управление отчетами:** Создание, чтение, обновление и удаление отчетов о выполненных задачах.
- **Гибкая система разрешений:** Использование стандартных ролей и возможностей WordPress для контроля доступа к отчетам.
- **REST API:** Предоставление программного интерфейса для взаимодействия с отчетами из внешних приложений.
- **Интуитивный интерфейс:** Удобное отображение и редактирование отчетов на фронтенде с использованием AG Grid (ранее Handsontable).
- **Экспорт данных:** Возможность экспорта отчетов в формате CSV.

## Установка

1. **Загрузка:**
    - Скачайте последнюю версию плагина с GitHub.
    - Распакуйте архив.
2. **Загрузка на сервер:**
    - Загрузите распакованную папку `in-employee-reports` в директорию `/wp-content/plugins/` вашего сайта WordPress.
3. **Активация:**
    - Перейдите в раздел "Плагины" в административной панели WordPress.
    - Найдите "in-employee-reports" и нажмите "Активировать".

## Использование

- **Настройка разрешений:** После активации плагин автоматически добавит необходимые возможности к стандартным ролям WordPress. Администраторы могут управлять этими разрешениями.
- **Доступ к отчетам:**
    - Администратор может создавать страницу для редактирования отчетов через специальный шорткод `[in_employee_reports]`, размещенный на любой странице WordPress.
    - Руководители и администраторы могут просматривать и редактировать отчеты других сотрудников.
- **Интеграция с внешними приложениями:** Для взаимодействия с REST API плагина используйте **встроенные пароли приложений WordPress**, которые можно сгенерировать в профиле каждого пользователя (`Пользователи` -> `Профиль`).

## Разработка

- **Архитектура:** Плагин построен на принципах KISS (Keep It Simple, Stupid), используя стандартные механизмы WordPress для управления ролями и возможностями (`map_meta_cap`).
- **Основные компоненты:**
    - `in-employee-reports.php`: Точка входа плагина.
    - `Plugin.php`: Центральный координатор.
    - `PermissionsManager.php`: Управление пользовательскими разрешениями (capabilities).
    - `Report.php`: Управление пользовательским типом записи "Активность" (Activity CPT).
    - `activity-rest-controller.php`: REST API для CRUD-операций с отчетами.
    - `Settings.php`: Управление настройками плагина.
    - `Frontend.php`: Отображение интерфейса отчетов на фронтенде.
- **Фронтенд:** Для отображения и редактирования отчетов используется библиотека **AG Grid (Community Version)**, обеспечивающая высокую производительность и функциональность.
